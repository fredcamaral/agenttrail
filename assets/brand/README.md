# Agent Trail logo set

- `agenttrail-app-icon-master.png` — full-color pastel master for app stores, social avatars, and large promotional uses.
- `agenttrail-app-icon-dark.png` — matching dark-theme master with the same composition and route geometry.
- `app-icon-*.png` — ready-to-use raster sizes. Use 32 or 64 pixels in the product UI and 512 or 1024 pixels for distribution.
- `app-icon-dark-64.png` — dark-theme raster sized for the product header.
- `agenttrail-mark-dark.*` — white route mark with an amber live node, for dark surfaces.
- `agenttrail-mark-light.*` — near-black route mark with an amber live node, for light surfaces.
- `agenttrail-mark-white.*` — one-color white mark for photography and constrained printing.
- `agenttrail-mark-black.*` — one-color black mark for documents and constrained printing.

Keep clear space around the mark equal to at least one endpoint diameter. Do not recolor individual route segments, add a container behind the transparent mark, or place it over a similarly bright background.
